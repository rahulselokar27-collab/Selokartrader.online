## 🚀 GitHub Pages पर Deploy करने के Steps

**Step 1** – GitHub पर Login करें → Repo खोलें

**Step 2** – सभी files upload करें (`index.html`, `style.css`, `script.js`, `CNAME`, `images/`)

**Step 3** – **Settings → Pages → Branch: main → Save**

**Step 4** – GoDaddy DNS में यह Records add करें:

| Type | Name | Value |
|------|------|-------|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | rahulselokar27-collab.github.io |

**Step 5** – GitHub Pages → Custom Domain → `selokartrader.online` → ✅ Enforce HTTPS
